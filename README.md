# AWS EC2 vs Serverless Research

## Research Title

Experimental Evaluation of EC2-Based and Serverless Architectures for Bursty Web Application Workloads on AWS: Performance, Scalability, and Cost Trade-offs

## Research Purpose

This repository contains the experimental implementation, methodology, workload definitions, raw measurements, processed datasets, analysis, and reproducibility materials for a comparative evaluation of EC2-based and serverless AWS architectures.

## Architectures

1. Fixed-capacity Amazon EC2 architecture
2. AWS Lambda + Amazon API Gateway serverless architecture
